= 거인의 노트
:toc: left

[quote]
거인의 노트, 김익한 저, 다산북스 출판, 2023년 3월 14일 출간

== 내용

기록::
* 메모를 정리하여 활용하기 쉽게 만든다.
* 나에게 맞게 키워드 중심으로 요약한다.
* 다시 볼 수 있을 만큼 애정이 있어야 한다.

생각::
* 분류하여 생각한다.

목표 달성::
* 일상과 습관을 목표에 맞춘다.
* 우선순위에 따라 계획을 세우고 실천한 후 평가한다.
* 중심을 수시로 상기한다.

공부::
* 정보에 이야기를 붙여 지식을 만든다.
* 지식을 조합해 활용하여 지혜를 만든다.
* 요약하고 종합하여 설명할 수 있도록 한다. 

다이어리::
* 주간 목표를 세운다.
* 할 일과 핵심성공요인을 적는다.
* 핵심 할 일을 적는다.
* 시간별, 주제별로 요약한다.
* 평가한다.
* 하루, 일주일, 1년 단위로 요약한다.

== 감상

기록의 효율성을 높이는 데 도움을 많이 받았다.
키워드 중심으로 나에게 맞게 요약하는 게 기록하는 시간과 양을 많이
줄여줬다.
양이 줄어드니 생각도 더 정돈되고 다시 보기도 수월해졌다.

아직은 책에 대한 기록을 주로 하는데 다양한 주제에 대해 기록해보면 좋을 것
같다는 생각이 들었다.
책에서 기록을 권하는 주제가 꽤 많은데 조금씩 시도해볼 생각이다.

책은 주제별 기록 방법으로 목차가 구성된 것 같다.
기록의 핵심 방법에서 세분화한 것이다보니 중복되는 내용이 꽤 있었다.

기록을 통한 성장을 강조하고 인생까지 이야기한다.
나는 이전에 했던 생각을 기억하고 싶어서 기록하기 시작한 거라 과하게
느껴졌다.
서술이 단정적으로 느껴져 불편한 마음이 있기도 했다.
